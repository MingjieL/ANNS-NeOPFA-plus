This repository contains the source code and experimental scripts for our NeOPFA method.

### 1. Data Preparation

Before running the project, you first need to download the corresponding dataset and partition it. For the base and query datasets, the code requires binary float format data, while the model training requires txt format data.

For the base dataset, we first use the MATLAB code in the `pqbf_kmeans` folder to perform K-means clustering to build a cluster index. Please refer to the PQBF paper for details on the indexing process. Taking the SIFT1B dataset as an example, the K-means index creation process is as follows:

```bash
cd ./pqbf_kmeans/data_mat
matlab -batch "generate_mat_sift1b"
cd ../matlab
matlab -batch "data_generation_sift1b"
```



### 2. Model Training

After preparing the data, our solution requires training three models (H, F, and G).

To train model H, you first need to partition the corresponding training set and query set. Before running the code, ensure that the Python dependencies are installed:

```bash
cd ./python
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Then, train model H:

```bash
python3 sift1b_model_H_train.py
python3 sift1b_model_H_map.py
```

Similarly, training model F requires preparing the training query set and the corresponding cluster labels. Run the following code:

```bash
python3 sift1b_model_F_train.py
```

The training of model G depends on the hash codes generated by the previous model H. After selecting a portion of the training data from the original dataset and the corresponding hash codes, run the following code:

```bash
python3 sift1b_model_G_train.py
```



### 3. Hash code reassembly

After all models are trained, in order to improve the efficiency of accessing hash codes during the re-ranking stage of queries, it is necessary to reorganize the hash codes generated by model H, so that more similar hash codes are closer in physical space on the disk. The implementation method is achieved through two-layer clustering (K1=64, K2=256). The specific implementation code process is as follows:

```bash
cd ./hashcode_reassembly
g++ sift1b_hashcode_split.cpp -o sift1b_hashcode_split
./sift1b_hashcode_split
cd ../python
python3 subcluster_division.py
cd ../hashcode_reassembly
g++ sift1b_hashcode_reassembly.cpp -o sift1b_hashcode_reassembly
./sift1b_hashcode_reassembly
```



### 4. Index Building

Once all three models are trained, you can proceed to the index building phase for the base dataset. We use CMake for project management:

```bash
cmake -S . -B build
cd build && make -j8
```

After compiling the project, run the following script to create the index:

```bash
cd ./script/sift1b
sh sift1b_index.sh
```



### 5. Retrieval Testing

After creating the index, you can enter the testing phase. First, prepare the query dataset and corresponding groundtruth file. Then, execute the corresponding query script to obtain the test results of the paper:

```bash
cd ./script/sift1b
sh sift1b_step01_search.sh
cd ../../python
python3 sift1b_model_G_map.py
cd ../script/sift1b
sh sift1b_step02_search.sh
```
